# Certificates & Documents Directory

Place your certificate PDFs, diplomas, and credential documents in this directory to serve them permanently in your portfolio.

### Recommended Naming Convention:
- `ml-internship-cert.pdf`
- `best-trainee-cert.pdf`
- `aws-cloud-cert.pdf`
- `diploma-cert.pdf`

You can also upload certificates directly using the **Upload Documents** button on your live website.
